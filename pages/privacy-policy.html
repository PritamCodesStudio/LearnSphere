1. Scope of this notice

This notice describes the data handling of the LearnSphere Academy demonstration website as delivered in this project folder. It is a static HTML, CSS and JavaScript site. There is no server-side application, account system, payment processor or email service connected to it.

If you adapt this project into a real service, you will need a new privacy notice that reflects your actual data collection, legal basis and retention practices.

2. What is stored in your browser

The demo uses your browser's localStorage (and occasionally sessionStorage) to make the interface feel continuous. The following demo keys may be created:

  • learnsphere.theme — your light or dark theme preference.
  • learnsphere.users — demo account names, email addresses and a browser-generated password hash. Never a raw password.
  • learnsphere.session — the current demo session, used to personalise the header and dashboard.
  • learnsphere.saved and learnsphere.favorites — course slugs you have saved or favourited.
  • learnsphere.enrollments and learnsphere.progress — sample enrollment and lesson-completion state.
  • learnsphere.activity — a short local list of demo actions for the dashboard.
  • learnsphere.messages, learnsphere.reviews and learnsphere.newsletter — anything you type into the demo forms.
  • learnsphere.demoSeeded and view preferences — small flags used to set up the demo.

These values stay on your device. They are readable by scripts running on this site and can be removed by clearing site data in your browser.

3. What is not collected

  • No real account is created and no identity is verified.
  • No payment details are requested or processed.
  • No analytics, advertising or session-recording tools are included.
  • No message, review or newsletter entry is sent to a server or inbox.
  • No precise location, device fingerprint or contact list is accessed.

Because there is no backend, the project owner cannot see your local demo activity. That also means there is no one to recover a lost demo password.

4. How demo data is used

Local data is used only to demonstrate interface behaviour: remembering a theme, showing saved courses, calculating sample progress, validating forms and rendering the dashboard. It is not used for profiling, marketing or any automated decision.

5. Cookies and third parties

This project does not set cookies of its own. It uses browser storage, which is a different mechanism.

The pages request fonts from Google Fonts. That request may share standard technical information, such as your IP address and browser details, with Google. If you need a fully self-contained deployment, you can remove the Google Fonts links and rely on the system font fallbacks defined in the stylesheet.

Social and external links in the footer point to placeholder destinations and open in a new tab. Their privacy practices are not controlled by this project.

6. Your choices and control

You can clear every demo value by using your browser's “clear site data” or “clear browsing data” option for this site. You can also use the reset control in the demo dashboard. Clearing data removes local accounts, progress, saved courses, messages and reviews.

Do not enter real personal information, real passwords or sensitive details into any demo form.

7. Security limitations

The demo hashes passwords with the Web Crypto API when available, with a non-cryptographic fallback under some local file conditions. This reduces the chance of a raw password being stored, but it is not secure authentication. Local storage can be inspected, altered or deleted by anyone with access to the browser profile.

Never reuse a real password. A production platform would require a server, secure password hashing, rate limiting, email verification, session protection and a formal security review.

8. Children

This demonstration is intended for a general audience interested in frontend design. It does not knowingly collect information from children. Because no data leaves the browser, there is no server-side record to delete.

9. Changes to this notice

As a portfolio project, this notice may be updated when the demo changes. The date at the top of the page indicates the current version. Material changes to a real service would require appropriate notice and, where necessary, consent.

10. Contact

Questions about this demo can be sent through the contact form. Remember that the form stores your message locally and does not deliver it. The placeholder address hello@learnsphere.example is for demonstration only.
